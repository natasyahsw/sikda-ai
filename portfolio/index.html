SIKDA AI Platform

Front-End Developer
  • Built an AI-powered regional financial dashboard (SIKDA AI) using React and Vite for the Microsoft AI Impact Challenge Hackathon, enabling real-time APBD budget monitoring across 8 sectors and 10 sub-districts.
  • Engineered 4 core modules — Interactive Dashboard with Recharts visualizations, Budget Transparency Portal with drill-down search, AI-Powered Anomaly Detection system, and an Azure OpenAI Chatbot for natural-language financial Q&A.
  • Designed a sleek dark-mode glassmorphism UI with responsive layout, gradient cards, animated transitions, and donut/area/bar charts to present Rp 8.75T budget data intuitively.
  • Integrated Microsoft Azure AI services with intelligent fallback to rule-based analysis, supporting multi-city data switching (Bandung, Surabaya, Semarang).
